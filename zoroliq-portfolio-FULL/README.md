# Emma Sargsyan Portfolio

A responsive static portfolio website built with HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

Upload the folder to GitHub and import the repository into Vercel, or drag the folder into Netlify Drop.

## Update content

- Main content: `index.html`
- Styling: `styles.css`
- Interactions: `script.js`
- Images/videos/resume: `assets/`
