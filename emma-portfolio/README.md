# Emma Sargsyan Portfolio

A static portfolio website for Emma Sargsyan focused on data analytics, automation, product development, Client Flow Systems, and FlowSuite.

## Local preview
Open `index.html` directly or use the VS Code Live Server extension.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: **Other**.
4. Root directory: the folder that directly contains `index.html`.
5. Leave build and output commands blank.

## Main files
- `index.html` — page content
- `styles.css` — visual design
- `script.js` — reveal animations and project video modal
- `assets/images/emma-sargsyan.jpg` — profile photo
- `assets/docs/Emma-Sargsyan-Resume.pdf` — downloadable resume
