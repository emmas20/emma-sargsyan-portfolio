02 / Product
Live MVP · Founder & sole developer

app.zoroliq.com — booking software for appointment-based businesses

Zoroliq’s own SaaS platform. I designed the data model, built the full-stack app, and shipped a working MVP that lets a service business manage its schedule without double-bookings. The next layer is automation and AI-assisted workflows.

01

Authentication & onboarding

Secure sign-up and login, plus a guided onboarding flow that sets a business up with its services and hours.

02

Booking & availability

Businesses define services, working hours, and availability; customers book open time slots.

03

Conflict-prevention scheduling

Slot generation runs in PostgreSQL, with database-level constraints so overlapping appointments can’t be saved.

04

Multi-tenant data security

Row-level security keeps each business’s data isolated at the database layer, not just in app code.

scheduling.sqlsimplified illustration
-- Overlapping bookings are rejected by the database itself
ALTER TABLE bookings
  ADD CONSTRAINT no_double_booking
  EXCLUDE USING gist (
    business_id WITH =,
    tstzrange(starts_at, ends_at) WITH &&
  );

-- Tenant isolation via row-level security
ALTER TABLE bookings ENABLE ROW LEVEL SECURITY;
